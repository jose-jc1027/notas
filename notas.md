# Instrucciones: blanco.py

## Descripción

Este script de Python contiene dos componentes principales:

### 1. Función `contar()`

Imprime los números del 1 al 2027 en la consola. Ideal para practicar ciclos `for` y funciones básicas en Python.

### 2. Clase `Hola`

Una clase interactiva que solicita el nombre y la edad del usuario al instanciarse y genera un saludo personalizado.

**Características:**

- Solicita nombre y edad del usuario
- Manejo de errores para entrada de edad inválida
- Método `saludo()` que muestra un mensaje personalizado

## Cómo usar este script:

1. Guarda este código en un archivo con extensión `.py`, por ejemplo: `blanco.py`

2. Abre una terminal o consola de comandos

3. Navega hasta la carpeta donde guardaste el archivo

4. Ejecuta el script con el comando: `python blanco.py`

5. El script ejecutará automáticamente:
   - La función `contar()` (mostrará números del 1 al 2027)
   - Creará una instancia de la clase `Hola` (solicitará tu nombre y edad)
   - Mostrará un saludo personalizado

## Ejemplo de ejecución

```
1
2
3
...
2027
¿Cuál es tu nombre? Juan
¿Cuál es tu edad? 25
Hola Juan, tienes 25 años.
```
